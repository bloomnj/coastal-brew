# Coastal Brew

Demo:  https://coastalbrew.suntheory.net
Coastal Brew is a responsive static landing page for a coastal-inspired coffee brand. The site presents the brand philosophy, product collection, crew profiles, and contact details using a single HTML page with custom CSS and local image assets.

## Features

- Fixed navigation with anchor links to each page section
- Full-screen hero banner with coastal coffee branding
- Responsive product collection cards
- Crew profile cards with photography
- Contact section with location, phone, email, and brand logo
- Mobile and tablet layouts handled with CSS media queries
- Google Fonts integration using Inter and Playfair Display

## Editing the Site

- Update page content and section markup in `index.html`.
- Update layout, colors, spacing, and responsive behavior in `assets/css/style.css`.
- Keep browser reset styles in `assets/css/reset.css`.
- Replace or add visual assets in `assets/img/`, then update image paths in `index.html` or `style.css` as needed.

## Main Sections

- `#hero-banner` - primary brand message and call-to-action
- `#philosophy` - brand philosophy and sourcing story
- `#collection` - product categories and coffee offerings
- `#crew` - team member profiles
- `#contact` - address, phone, email, and footer details

## Notes

The page uses Google Fonts, so an internet connection is needed for the exact typography to load. If fonts are unavailable, the browser will fall back to standard serif and sans-serif fonts.
